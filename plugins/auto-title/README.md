# 标题自动生成

为新建任务自动生成简短标题，支持随任务目标更新。需要 Lexora 0.12.0 及以上版本。

## 使用

启用后，在新任务的主回复开始时后台生成标题，默认仅成功命名一次。已有任务、手动标题及来源不明的历史标题保持不变。内容不足或请求失败时，可在下次输入时重试。

## 配置

- **生成标题的模型**：留空时使用任务当前模型。
- **允许随任务目标更新**：默认关闭；开启后，每轮回答完成时评估目标变化，必要时更新自动标题，并产生额外模型用量。

## 权限与限制

仅读取触发任务的有限消息文本，不读取附件内容或工具输出。标题生成需要调用模型和修改任务标题的权限；无效或截断输出不写入标题。
