# 标题自动生成

首条有效任务输入提交后，在后台生成简短标题。默认成功命名一次；内容不足或请求失败时，下次输入可再尝试。命名不占用主对话工具，也不会等待回答完成。

- 在插件设置中选择模型，留空使用任务当前模型。关闭「启用」时，其余设置禁用并保留原值。
- 「允许随任务目标更新」默认关闭；开启后，后续回答完成时评估主目标是否明显变化，必要时更新自动标题。每次评估会产生额外模型用量。
- 手动标题和历史来源不明的标题自动保留；可通过任务顶部的「更多操作 → 重新生成标题」主动替换。
- 需要读取触发任务的有限消息文本和调用模型的权限；不读取附件内容与工具输出。

生成过程和结果显示在任务历史中，重启后仍可查看；自动跳过不刷屏。

修改输入、切换分支、删除任务或停用插件会使过期调用失效。你在生成期间手动改名时，以手动命名为准。
