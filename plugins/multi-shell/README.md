# 多 Shell · 命令执行

检测本机已有 Bash、Git Bash、Zsh、POSIX sh、PowerShell 7+、Windows PowerShell 5.1 和 cmd。

需要 Lexora 0.15.0 或更新版本。安装后打开「设置 → 运行时 → 命令解释器」，原生表格每行对应一个 Shell，可查看检测状态、版本和只读路径，并启用候选、调整优先级。

默认自动检测；点击「重新检测」刷新结果。需要指定安装位置时点击「选择文件」，选择你信任的本机解释器；点击「恢复自动」清除自定义路径。无需手填路径。选择文件本身不会运行程序，保存后检测会调用固定版本探针。未找到的候选显示原因，不会安装解释器。

优先级 0 保持平台默认，正数越小越优先。配置从下一轮任务生效。当前候选执行支持 Linux/Windows；macOS 暂不开放。宿主 sh/zsh/cmd 命令会保守请求审批；cmd 仅接受单行。

这是纯声明插件，无独立检测页面或命令。文件选择和配置保存由 Lexora 原生设置处理，不授予插件文件访问或命令执行权限；执行仍由核心按现有授权处理。不支持 WSL、PTY 或交互式终端。
