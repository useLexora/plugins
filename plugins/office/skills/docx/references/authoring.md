# 结构与格式

用语义结构组织文稿：标题有层级，段落表达单个要点，真正的列表用列表节点，表格用于比较或数据，不用连续空格模拟布局。保留模板已有字体、间距、编号和未修改区域，避免整篇重建损失其它对象。

空白文档插入示例：

```json
{"afterBlockIndex":-1,"html":"<h1>项目简报</h1><p>这里填写核实后的目标与结论。</p><table><tr><td>项目</td><td>负责人</td></tr><tr><td>验收</td><td>待确认</td></tr></table>"}
```

这是 insert_content 的 input。执行后 read_blocks 检查实际块顺序，再使用原 schema 的 apply_ops 细化格式。长文按章节分批，保留每批操作回执；不要调用原版 GenOffice 中会启动系统 writer 的 write_document，它不属于本套件公布的操作。

replace_blocks 只覆盖确认要改的块，涉及已有表格或内嵌对象时先读结构。单段引用替换继承原格式；跨段操作改用块级工具。修订的接受/拒绝仅在用户明确要求处理修订时进行。

页眉页脚、批注和页面 metadata 可出现在上下文中，但可读不代表本次工具支持写入；按 capabilities 判断。当前 DOCX undo 主要覆盖正文编辑事务，不能把外部 metadata 当作同一撤销历史。完成检查包含正文/结构回读和真实文件导出；界面能显示不等于所有排版在 Word 中完全一致。
