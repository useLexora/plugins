# 布局与创作

先按受众和目的确定各页要点，再选择标题/正文/图表或比较结构。沿用已有主题、画布和版式。每页保持明确的信息层级，使用少量一致的字号和间距，不用缩小字体掩盖过密内容。

PPTX 的底层几何使用 EMU，1 英寸 = 914400 EMU，1 点 = 12700 EMU；文字 fontSize 按工具 schema 的点数。使用 read_slide 返回的画布尺寸决定位置，不把像素数直接填入 EMU。

为第 0 页添加独立文本框的 apply_ops 示例：

```json
{"ops":[{"op":"addElement","target":{"slide":0},"kind":"textbox","offset":{"x":914400,"y":685800,"cx":7315200,"cy":914400},"paragraphs":[{"runs":[{"text":"项目简报","bold":true,"fontSize":32}]}]}]}
```

提交前先按能力 schema 设置 dryRun。动作的 target、字段和支持类型以 capabilities/op 文档为准；不要把原版所有布局脚本或模型生成能力都视为可用。

检查顺序：结构/文字回读 → check_layout → render 实际图片。布局审计通过不保证视觉满意；看标题是否换行、正文是否截断、图形是否遮挡、边距是否统一。渲染也不能代替对未支持 OOXML 对象的保真检查。保留模板中未修改的元素；需要复杂图表或母版编辑时先确认真实操作能力。
