# 喝水提醒小助手

按设定的间隔发送系统通知，提醒喝水与休息，不调用模型。

安装后在侧栏打开「喝水提醒」，开启提醒、设置间隔并保存。使用「发送测试通知」检查通知是否正常显示。

从 1.0.0 更新后，在插件管理中重启插件即可生效，原来的提醒开关和间隔会保留。

关闭页面或最小化 Lexora 后仍会提醒；退出应用后暂停，重新打开后恢复。休眠期间错过的提醒不会补发。禁用插件立即停止提醒；卸载删除定时任务，重新安装需再次开启。

需要系统通知和后台定时任务权限，不需要文件、网络或模型访问。实际通知展示遵循 Lexora 和操作系统的通知设置。

适用于 Lexora 0.9.1 及后续 0.x 版本。
