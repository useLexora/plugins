# Lexora Plugins

Lexora 插件源码与插件市场目录，汇集官方插件和社区作品，让每个人都能按自己的习惯扩展 Lexora。

欢迎使用、反馈，也欢迎分享你开发的插件。插件市场已支持链接第三方作者独立维护的插件，源码与发布包可以保留在作者自己的仓库，无需迁入本仓库。

## 插件列表

以下列出本仓库维护的插件及市场已收录的社区插件。点击插件名称查看使用说明或访问项目仓库；实际上架情况以 Lexora 插件市场为准。

### 官方插件

| 插件 | 作者 | 功能 |
| --- | --- | --- |
| [标题自动生成](plugins/auto-title) | Lexora | 自动生成任务标题，可随任务目标更新，并保留手动命名。 |
| [任务残留清理](plugins/legacy-task-cleanup) | Lexora | 清理旧版已移除任务的本地残留，不影响现有任务和外部文件。 |
| [Lexora Office](plugins/office) | Lexora | 编辑本地 Word、Excel、PowerPoint 和 PDF 文件，支持选区引用、任务协作与文档库。 |
| [Lexora Local Models](plugins/local-models) | Lexora | 发现、下载和运行本地模型，支持对话、图像理解、语音转写、朗读、图像生成与文字识别。 |
| [多 Shell · 命令执行](plugins/multi-shell) | Lexora | 检测本机命令解释器，配置启用状态、路径与优先级；命令仍由 Lexora 核心受控执行。 |
| [Lexora 主题](plugins/themes) | Lexora | 提供经典、森林、鸢尾、玫瑰与琥珀五组主题，各含浅色和深色。 |
| [鲸鱼娘](plugins/whale-girl) | Lexora | 海盐与深海两款主题，搭配蓝靛配色与鲸鱼娘角色插画。 |
| [喝水提醒小助手](plugins/water-reminder) | Lexora | 按设定间隔发送系统通知，提醒喝水与休息，无需调用模型。 |

## 安装与开发

在 Lexora 插件市场中浏览并安装已上架的插件，也可下载 `.lexora-extension` 插件包，在「插件 → 安装插件包」中安装。

开发时可加载插件的开发目录；需要构建的插件，请按其说明生成并加载对应目录。兼容要求、配置、构建与打包步骤见各插件的 README。

## 欢迎投稿

无论是提高效率的小工具、个性化主题，还是新的工作流集成，都欢迎分享给更多 Lexora 用户。

- **分享独立插件**：在自己的仓库维护源码与发布版本，通过本仓库的 Issue 或 Pull Request 提交收录申请，以链接方式加入插件市场。
- **参与现有插件**：欢迎提交功能改进、问题修复、文档补充或使用建议。
- **反馈使用问题**：本仓库维护的插件可在这里提交 Issue；第三方插件的问题请优先反馈到对应作者的仓库。

提交插件时，建议附上名称与功能简介、作者及仓库链接、使用说明、兼容的 Lexora 版本、所需权限、许可证，以及可下载的插件包或发布页面，方便大家了解和安装。

第三方插件由各自作者维护。安装前请查看项目说明、来源与权限要求，并遵循相应许可证。
